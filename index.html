Favorites

Syncs with heart favorites in Navidrome and other clients. No playlist creation needed. Favoriting songs will add them here; favoriting albums or artists will not automatically favorite their songs.

YouTube Search Optional

YouTube will only be included in search results if the key is filled, allowing you to play songs not in your library. Search RapidAPI for these two APIs and subscribe (both have free tiers), using the same key: yt-api (search) and youtube-mp36 (audio extraction). The free tier has rate limits, you can enter multiple keys separated by commas, they will be used randomly. See project README for detailed steps and troubleshooting.

AI Search Correction Optional

Voice or manual input easily produces homophones. After filling in the key, search will first let the model smooth out the words; results for both original and corrected words will be listed. Any service compatible with OpenAI /chat/completions can be used. Leave blank to completely disable.

Self-hosted Search Backend Optional · Advanced

If you run a small self-hosted search/streaming service, fill in the address here to connect it. Interface specifications are in docs/backend-api.md in the repository. Leave blank to remove this section.

Voice Request & iOS Shortcuts Optional

Normal playback does not require this service. Deploy server/voice.py from the repository, to receive dictation text from iOS Shortcuts; web microphone can also be used after configuring the server transcription API. Music account is still only sent to Navidrome, transcription API Key stays on the server. See docs/voice.zh-CN.md for deployment and Shortcuts steps.
